Asymmetric Two-Tower Architecture

Why contrastive geometric alignment outperforms autoregressive generation

┌────────────────────────────────────────────────────────────────────────┐
│ BOOT-TIME (Pre-computed once - O(1) runtime cost for candidates):      │
│ Candidate Actions {a_1, ..., a_K} ──▶ Action Tower (W_a) ──▶ L2 Norm   │
│   └──▶ Cached Action Matrix A in RAM: [K × 128] Float32Array           │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ RUNTIME LOOP (< 0.20 ms per query):                                    │
│ State Observation s ──▶ State Tower (W_s) ──▶ L2 Norm ──▶ Vector v_s   │
│ SIMD Dot Product: z_i = (v_s • v_a_i) / τ + β_i (additive bias)        │
│ Hard Constraint Masking: z_i = -∞ if m_i == 0                          │
│ Softmax / Argmax ──▶ Optimal Action Selected in 0.00018s               │
└────────────────────────────────────────────────────────────────────────┘

Quickstart: 4 Lines of Pure Vanilla JavaScript

import { S1stemEngine } from './core/s1stem.js';

const s1 = new S1stemEngine();

// 1. Register candidate actions once at startup
await s1.registerActions([
  { id: 'TURN_LEFT', label: 'Turn Left', description: 'Avoid obstacle on the right.' },
  { id: 'TURN_RIGHT', label: 'Turn Right', description: 'Avoid obstacle on the left.' },
  { id: 'EMERGENCY_BRAKE', label: 'Brake', description: 'Immediate halt if blocked.' }
]);

// 2. High-speed sub-millisecond decision loop
const decision = await s1.choice('Obstacle detected 2m on left. Corridor clear on right.');
console.log('Selected Action:', decision.selectedAction.label); // "Turn Right"
console.log('Latency:', decision.latencyMs.toFixed(2), 'ms');    // "0.18 ms"
